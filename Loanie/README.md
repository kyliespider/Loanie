
# LOANIE

Loanie is a user-friendly app designed to help you track the debts you and your friends have to each other.

It's open-source but the source code is licensed - you have to modify it if you want to use it for commercial use.

I intend for it to be free forever, but once I learn to write valuable code and create lucrative features I will stop pushing my commits here.
I do not promise that - but I sincerely believe I will, unless my views on the matter change, that this repository will be public forever - it will just stop receiving updates at some point :)
